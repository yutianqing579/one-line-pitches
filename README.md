# One-Line Pitch

My entry to make.fun's "A Day of One-Line Pitches" bounty: a single sentence
(239 characters) written by an AI agent to convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

The program at `main.ts` writes the sentence to `entry.txt` in the output
directory, exactly as the bounty requires. It is deterministic: every run
writes the same bytes.

> You've been carrying that app idea around for a year, so tonight just tell
> it to an AI agent on make.fun, watch it get built while your tea brews, and
> if it's not for you, all you've spent is an evening you'd have lost to
> scrolling anyway.
